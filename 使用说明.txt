先完整解压 ZIP，再进入 ai-treehole 文件夹。

第一次使用本机语音转文字
  双击“安装语音模型.cmd”，等它建好环境、装依赖、下载模型（约 230MB）。
  装完会自动用 samples 里的样本跑一遍自检，看到转写文本就说明通了。
  整个 ZIP 必须先解压到普通文件夹，不要在压缩包预览里直接双击 .cmd。

日常使用
  双击“启动本地树洞.cmd”，服务起来后会自动打开网页。
  只想看界面不开服务，也可以直接双击 index.html，但此时语音转文字不可用。
  127.0.0.1 链接只在本机服务运行时有效，不能作为永久分享链接。

语音转文字
  录音在本机完成：先解码重采样成 16kHz WAV，再交给本地 SenseVoice 模型。
  音频不出这台电脑，只把文字放进输入框，确认或改完再发送。
  浏览器不给麦克风权限时，先在地址栏旁的权限设置里放行。

声音线索
  消息下方的“声音参考”来自本地模型，会显示情绪倾向（如“声音偏低落”），以及哭腔、叹气。
  识别刻意偏保守：宁可漏掉，也不误标成“你在哭”。
  只用合成样本和少量语音验证过，真人哭腔、叹气还没有样本，报不出准确率。
  只叹一口气、没说话时，会提示“没有听清说话内容，但听到一声叹气”。

回复来源
  默认是规则回复（模板），不是大模型生成；在 .env 里配好对话服务 key 才会走真实模型。

情绪帮助链接
  发送“我今天不开心”“最近压力很大”“晚上睡不着”，回复后会给出匹配的音乐、呼吸、感官或睡前练习链接，均可离线打开。
  可关闭自动弹窗，之后从消息下方“查看 2 个实操链接”重新打开。
  安静倾听和禁止开导模式不主动推荐；风险表达优先显示安全支持。
  本版音乐是本地合成舒缓音，日常练习不能替代专业诊疗。

排查
  npm run check:asr            转写 samples 里所有样本，打印文本、情绪、声音线索与耗时
  npm run check:asr -- 某文件.wav   转写指定录音
  npm test                     跑全部自检（缺 .venv 或模型时相关用例自动跳过）
