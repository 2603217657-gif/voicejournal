# AI 情绪语音树洞 · 本地课程 Demo

## 运行

先将 ZIP **完整解压**，进入 `ai-treehole` 文件夹。最稳妥的演示方式是直接双击 `index.html`：它会在本机浏览器打开离线网页版，无需 CMD、Node.js 或持续运行的服务。离线版提供文字对话、五种倾听模式和本机历史记录；回复是规则演示。录音与浏览器语音识别是否可用取决于浏览器权限和支持情况。

若已安装 Node.js 20 或更新版本，可以双击 `启动本地树洞.cmd`。脚本会等待服务就绪后再打开 `http://127.0.0.1:4173/`；如果找不到 Node.js 或服务未能启动，就打开离线版。看到 `AI Treehole Server` 窗口时请保持它打开，关闭后 `127.0.0.1` 链接会失效。也可在项目目录运行 `npm start`。

要用本地语音转文字，先双击一次 `安装语音模型.cmd`（下载约 240MB，只需装一次）；没装模型时录音会自动退回浏览器自带的语音识别。

不要直接在 ZIP 预览界面里运行 CMD 或 HTML；要先解压整包，保持 HTML、CSS、JS 在同一个文件夹。如果 Windows 阻止 CMD，直接双击 `index.html` 即可使用离线演示版。

## 本次更新：情绪帮助弹窗与实操链接

- 发送“最近状态不太好”“我不开心”“压力很大”“睡不着”等内容时，树洞先回应感受，再展示两张匹配的帮助卡片；文字与语音转写后发送共用这一流程。
- 难过、孤独等：音乐放松与 5-4-3-2-1 感官练习；焦虑、压力大等：1 分钟呼吸与感官练习；疲惫：音乐与呼吸；失眠：睡前步骤与音乐。
- 四种练习均为项目内页面，支持离线打开。音乐使用 Web Audio 本地合成轻柔和声，点击后才播放，3 分钟后停止；呼吸练习为 4 秒吸气、6 秒呼气，共 1 分钟，可随时停止。切到后台会停止播放/练习。
- 音乐页面另附网易云音乐的固定“舒缓轻音乐”搜索链接，需联网，可能需要登录；不会携带用户对话。合成音和练习用于日常放松，不是专业音乐治疗，不承诺疗效。
- 可以关闭弹窗、按 Esc 返回，或关闭“自动显示帮助卡片”。消息下方的“查看 2 个实操链接”入口与会话一起保存，刷新后仍能打开。每个对话的自动弹窗至少间隔 5 分钟（刷新页面后重新计时）。
- 安静倾听、禁止开导以及明确表示不要推荐时，不主动给出卡片。自伤/轻生风险优先采用安全支持，不推荐普通放松资源，也不等待远程 AI 响应。
- 离线版使用中文关键词和常见否定表达规则，可能漏判或误判，不进行心理诊断。配置 AI 后，AI 负责自然语言安慰，链接仍来自固定资源目录，不使用模型随意生成的网址。

快速体验：完整解压后进入 `ai-treehole`，打开 `index.html`，发送“我今天不开心”。也可以在本地服务中体验。

开发验证：Node.js 20+ 下运行 `npm test`。已验证规则匹配、否定表达、倾听偏好、风险优先级、固定链接、本地 API 和模拟 AI 接口；浏览器中验证了自动弹窗、刷新后重新打开、练习页导航、音乐播放/停止、呼吸开始/停止。本地语音转写的验证见「本地语音模型」一节；第三方音乐平台访问仍未验证。

## 自定义倾听模式

对话区域可选择五种模式：安静倾听、温和共情、旁观者视角、轻轻提问、禁止开导。选择保存在当前浏览器，下次打开仍会记住。模式会传到后端；无 API Key 的规则演示回复也会按模式变化。自伤风险表达优先使用安全回复，不受模式限制。

文字回复在未配置 AI API Key 时是关键词规则演示，不是大模型生成。录音、历史记录和演示登录保存在当前浏览器，不跨设备同步。支持时可使用浏览器自带的语音识别。

## 本地语音模型（已跑通）

`transcribe.py` 现在调用 **sherpa-onnx + SenseVoiceSmall**（阿里达摩院模型，int8 量化约 240MB）做中文转写。它是纯 ONNX Runtime 推理，不依赖 ctranslate2 / PyTorch，避开了此前 Windows 上加载模型的原生崩溃。

首次使用双击 `安装语音模型.cmd`。它会自动挑本机最高版本的 Python（建议 3.11/3.12，最低 3.9）、建 `.venv`、装依赖、从 hf-mirror 下载模型到 `models/sensevoice`，最后用 `samples/` 跑一遍自检。

模型下载遇到镜像限流（HTTP 429）或网络中断会自动退避重试 4 次；huggingface 镜像不支持断点续传时（会返回 200 而不是 206）脚本会自动改为完整重下一次，不会把半截文件当成成品。`tokens.txt` 已经随包附带，通常只需要下 228MB 的模型本体。

**必须先把整个 ZIP 解压到普通文件夹（例如 `D:\treehole`），不要在 Windows 压缩包预览里直接双击 `.cmd`**——那种情况下只有被点开的那一个文件会被解到 `%TEMP%`，同目录的 `requirements.txt`、`prepare_model.py` 都不在，安装会报"Could not open requirements file"。安装脚本会检测这种情况并直接提示你。

手动等价命令：

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe prepare_model.py
```

验证方式：`npm run check:asr` 直接转写 `samples/` 下的样本并打印文本、情绪、事件与耗时。

实测记录（2026-11-09，i5-1135G7 / Python 3.13.16 / sherpa-onnx 2.0.1）：

- 9.0 秒疲惫语气样本 → 「今天真的挺累的，什么都不想做，也不太想说话，就想找个人待一会。」情绪 SAD，事件 Speech
- 7.68 秒带叹气样本 → 「唉，算了，说了也没用，我没事，你别管我了。」情绪 SAD，事件 Speech
- 模型耗时 2.1–2.2 秒，实时率约 0.25；HTTP 接口端到端 2.64 秒；17 项测试全部通过
- Python 3.9.2 也实测通过（numpy 2.0.2 / soundfile 0.13.1 / soxr 1.1.0 / sherpa-onnx 2.0.1 的 cp39 轮子），安装脚本在空环境里完整跑通

仍然没有验证、对外说明时必须保留的部分：

- 只用合成语音测过，真人手机录音（含噪声、方言口音）未测；
- 手机端录音要能走完「WebM 解码成 16 kHz WAV」这一步，尚未在手机上实测；
- 哭腔与叹气判别只在合成样本和两段真实合成语音上跑过，没有真人样本，报不出准确率（见下一节）。

前端录音链路也随之改变：`chat.js` 先用 `AudioContext` 把录音解码并重采样成 16 kHz 单声道 WAV 再上传（见 `toWav16k`），所以音频不出本机就能转文字，上传体积也从每秒几百 KB 降到 32 KB。服务端只接受 WAV，收到 WebM 会返回 415 `LOCAL_ASR_NEEDS_WAV`。

## 副语言线索：哭腔与叹气

文字会被改写，叹气不会被改写。这一层专门看声音本身，由 `paralinguistic.py` 提供，不引入 librosa / opensmile，只用 numpy + soundfile。

两件事分开做：

- **哭腔**：SenseVoice 自带 `Cry` 事件标签，这一条直接采信；另外用声学特征复核——浊音段内部基频抖动（jitter）。正常说话约 0.03，设计的哭腔样本 0.12。
- **叹气**：不在 SenseVoice 的标签集里，只能用规则找——句首或句尾要有一段听得见但没有浊音的呼气，且时长达到阈值。真正叹气时那段"气声"是实打实的，静默停顿时没有。

阈值取舍上刻意偏保守：宁可漏掉，也不误标。误判"检测到你在哭"对一个来倾诉的人伤害很大，所以正常说话的能量起伏、停顿比例这些容易误伤的指标只作为特征输出，不参与判定。

| 样本 | 哭腔 | 叹气 | 基频抖动 |
|---|---|---|---|
| 9.0s 疲惫语气（真实转写样本） | 否 | 否 | 0.015 |
| 7.68s 带叹气语气（真实转写样本） | 否 | 否 | 0.015 |
| `sample_sigh_cued.wav`（合成呼气） | 否 | **是**（0.75） | 0.0 |
| `sample_cry_cued.wav`（合成哭腔） | **是**（0.60） | 否 | 0.117 |

两段真实样本都没有误报。合成样本由 `scripts/make-cue-fixtures.py` 生成，用途只是验证"规则能被这种声学模式触发"，不代表真人准确率——这一点必须写在答辩材料里。

当录音里只有一声叹气、没有说话内容时，接口不会当成失败：返回空 `text` 加 `voiceCues.sigh = true`，前端提示「没有听清说话内容，但听到一声叹气。可以直接打字，或再说一遍」。

## API

`127.0.0.1` 只能在运行服务的电脑上打开；离线版的 `index.html` 可以把整包复制到另一台电脑后在那台电脑上打开。同一 Wi-Fi 可通过设置 `HOST=0.0.0.0`、放行防火墙端口并使用电脑局域网 IP 访问。跨网络访问需要一个可用的托管账号或服务器及 HTTPS 域名；此前的 `chatgpt.site` 链接在用户手机网络上被拦截。

## API

- `GET /api/health`：返回配置状态，含 `transcriptionEngine`（`sensevoice` / `remote` / `null`）、`emotionTags` 和 `voiceCues`（本地模型下为 `true`）。
- `POST /api/chat`：JSON 包含 `mode`（`quiet`、`warm`、`observer`、`gentle`、`no-advice`）和 `messages`；返回 `text`、`crisis`、`resourceIds` 等字段。资源 ID 对应 `support.js` 中的固定目录。
- `POST /api/transcribe`：请求体为 16 kHz 单声道 WAV（`Content-Type: audio/wav`）；成功返回 `text`、`emotion`、`event`、`duration`、`engine`，以及 `voiceCues`（`cry`、`sigh` 布尔值与 `cryScore`、`sighScore`、`reasons`）。非 WAV 在本地模型下会被 415 拒绝。

不要把 `.env` 或 API Key 上传到公开仓库。公开部署前还需完善鉴权、隐私与数据保留策略。

## 封存心事

当前对话右上角的「封存心事」会先显示确认弹窗，确认后播放约 2.8 秒的信纸入封、合上信封与盖印动画，并回到空白对话。系统设置减少动态效果时会直接展示完成状态。

封存针对整段已发送对话。回复或录音进行中、存在草稿或待发送录音时需先完成或清空。封存状态保存在当前浏览器；历史只显示通用标题和封存日期，不再提供查看或继续入口，仍可删除。此功能是界面封存，不是加密或销毁，原文和录音仍存于浏览器；本版没有定时解锁。
